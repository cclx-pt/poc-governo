# Governo CCLX — Especificações do Projeto

Este repositório documenta o **produto que pretendemos desenvolver** para o Governo institucional da Comunidade Cristã CCLX, no âmbito da prioridade **P7 — Redefinir a Cultura CCLX**.

## Documentação principal

1. **[Especificação Funcional](docs/ESPECIFICACAO_FUNCIONAL.md)** — objetivos, âmbito, módulos, utilizadores, processos, regras e critérios de aceitação.
2. **[Especificação Técnica](docs/ESPECIFICACAO_TECNICA.md)** — tecnologias, dados, autenticação, segurança, qualidade e requisitos não funcionais.
3. **[Arquitetura da Solução](docs/ARQUITETURA.md)** — componentes, camadas, fluxos, separação de responsabilidades e evolução.

**Estado:** especificação para desenvolvimento futuro. Não representa uma aplicação em produção nem autoriza publicação.

> Existe código experimental e documentação histórica nesta branch, mas **os três documentos acima são as únicas referências principais do produto pretendido**. Não introduzir dados pessoais reais ou segredos neste repositório.
